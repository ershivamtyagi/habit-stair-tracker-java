# Site Publishing

This folder is a small static site for Microsoft Store support and privacy links.

## Pages

- `index.html`
- `privacy-policy.html`
- `support.html`

## Before publishing

- Replace `support@example.com` with your real support email.
- If needed, update the app name or wording.

## GitHub Pages

One simple approach:

1. Push this repository to GitHub.
2. In the repository settings, open `Pages`.
3. Set the source to deploy from the branch that contains the `site/` folder.
4. If you use a Pages workflow, publish the contents of `site/`.

## Netlify

Set the publish directory to:

```text
site
```

## Store URLs

After publishing, use:

- `https://<your-site>/privacy-policy.html`
- `https://<your-site>/support.html`
